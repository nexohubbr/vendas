📖 Como configurar (clique para ver)
  1. Acesse console.firebase.google.com
  2. Clique em "Adicionar projeto" → dê um nome → crie
  3. No menu lateral, clique em "Criação" → "Firestore Database" → "Criar banco de dados" → modo teste → escolher localização → concluir
  4. Clique na ⚙️ (engrenagem) → "Configurações do projeto"
  5. Em "Seus apps", clique no ícone </> (Web) → registre um app
